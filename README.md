# Missione Python

Gioco per imparare Python: il robot **Pyto** deve recuperare i pezzi del suo razzo su 6 pianeti, risolvendo 3 problemi su ciascuno (print, variabili, conti, input, if/else, cicli for).

- **Mappa stellare**: 6 pianeti × 3 problemi, con stelle, XP e gradi
- **Laboratorio**: editor libero per sperimentare
- **Modalità docente**: sblocca pianeti e soluzioni

Il codice Python gira direttamente nel browser grazie a [Skulpt](https://skulpt.org). I progressi vengono salvati nel browser (localStorage).

> Il **Registro della classe** condiviso funziona solo nella versione aperta su Claude; qui mostra un avviso.

Per pubblicarlo: *Settings → Pages → Deploy from branch → `main` / root*.
